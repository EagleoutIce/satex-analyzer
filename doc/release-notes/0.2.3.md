# Starts in devcontainers, says why when it cannot

### Playground

- `feat` **The text set so far, at every trace step.** A step of the trace shows the paragraph as set up to it, so after an `\else` you read what that arm typeset (`Hello, abab`); `satex trace` gives it as `set_so_far`. [`b92d718`](https://github.com/EagleoutIce/satex-analyzer/commit/b92d718)
- `fix` **The definition history shows again.** A later edit had dropped its view, so the dialog for a command's history opened empty in the playground and in VS Code. [`0ddb302`](https://github.com/EagleoutIce/satex-analyzer/commit/0ddb302)

### VS Code

- `fix` **The server starts in devcontainers.** Where no systemd user bus runs (containers, WSL) the extension still started the server in a user scope, which failed with "Failed to connect to user scope bus" and left only `write EPIPE`. It now tries the scope first and caps memory with `ulimit -d` where that fails, else runs on the server's own budget. [`786e1e0`](https://github.com/EagleoutIce/satex-analyzer/commit/786e1e0), [`3f34cf0`](https://github.com/EagleoutIce/satex-analyzer/commit/3f34cf0)
- `fix` **Every failed start says why and how to fix it.** A broken `satex.path` or bundled binary (wrong C library, musl, not executable) falls back to the next one, a server that dies before it answers or crashes later is reported with its reason, and a server that stays off says so, each with buttons to download satex, set the path, show the output or restart. [`786e1e0`](https://github.com/EagleoutIce/satex-analyzer/commit/786e1e0), [`3f34cf0`](https://github.com/EagleoutIce/satex-analyzer/commit/3f34cf0)
- `fix` **Windows packages of the extension again.** Packaging on Windows stopped at the webview scripts (it ran `esbuild` as a program, a `.cmd` there), so neither 0.2.1 nor 0.2.2 published the extension. [`802cbdf`](https://github.com/EagleoutIce/satex-analyzer/commit/802cbdf)

### Site and docs

- `docs` **Fair benchmark comparisons.** The charts and deltas count only documents every compared release read to the end, so reading further never counts against a release, and a new table sums each engine against the release before. [`899a58b`](https://github.com/EagleoutIce/satex-analyzer/commit/899a58b)
