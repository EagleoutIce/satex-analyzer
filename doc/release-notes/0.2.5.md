# Sound guesses, skipped unchanged builds, steadier CI

### Compile

- `perf` **`satex compile --system satex`: no build when nothing it reads changed.** Each pass records every file the engine opened. The next build compares their contents, the TeX search path and the listings of the directories it looked in, and returns the last result when nothing moved: a 195-page book 1.18 s → 0.02 s. A preamble the format dump cannot replay (glossaries before cleveref) is read by the run itself, no false `Extra \fi`. `compile.clock` says how often the clock counts (minute, or day when only `\today` reads it). One line on stderr says how many passes ran.
- `feat` **`satex compile` picks the build system.** `% arara:` runs arara, a `Tectonic.toml` Tectonic, else latexmk or the engine. `--system` or `compile.system` names one (latexmk, arara, tectonic, make, l3build, engine). `--view` opens the PDF in `compile.viewer`.
- `feat-fix` **CLI: settings found from any directory.** `satex lint -f x.tex` reads every `satex.yaml` above the current directory, not only its own. `--no-config` reads none, also for the project root and l3build settings. A `--filter` on a field no record has errs and names the fields. The texlog format shows the source line at `l.⟨line⟩`, split where the finding is.
- `perf` **Playground PDF: a warm engine per build.** `satex gui` builds each project in a directory of its own, where the last build left pdfTeX started on its format, waiting to open the main file (`compile.warm`). A body edit of the thesis example builds in 0.63 s → 0.48 s, the hello example 0.52 s → 0.39 s. `playground.compile_rest` builds without waiting for the analysis.
- `perf` **Playground PDF: no build where pdfTeX reads no edit, unchanged pages kept.** An edit inside a comment or of spaces TeX skips keeps the PDF shown, proven by the analysis (`satex/holds`): last key to page 1.77 s → 0.35 s on the rerun example. A page whose content and resources did not change keeps its image: a word typed in the thesis example redraws 1 page, not 5.
- `perf` **`satex compile --system satex`: incremental build.** The preamble is dumped once as a format and reused, the engine, BibTeX, Biber and makeindex rerun only on changed input. A body edit of the thesis example in the browser takes 0.57 s → 0.19 s (−67%). The playground's Compile uses it on `satex gui`.

### Caches

- `feat` **Cache reports and background setup.** `satex lint`, `query` and `explain` say in one line how many package caches they reused and built (`-v` lists them). `satex cache show` lists a package's cache files, sizes and variants. On first use satex asks to analyze kernels and packages in the background within `limits.cache_size`. `satex cache` shows its state, `satex cache stop` stops it (`cache.background`, `SATEX_NO_SETUP`).
- `perf` **Smaller, faster package caches.** datatool-base 55 → 24 MB (−56%), scrbook 40 → 25 MB (−38%), warm glossary replay 20% faster. `satex cache show` breaks bytes down by section.

### Lints

- `feat-fix` **Table precision with TeX Live 2025.** The `S`-column rule reads siunitx's round mode under its 2025 name too, so rounding columns stay quiet there.
- `feat-fix` **No false "never defined" after a missing package.** A name a missing or misspelled package would define is a warning that names the missing file, not a certain error: pdflatex stops at the file instead.
- `feat` **Quick fixes for package, reference and citation errors.** `unresolved-file` deletes the load of a package no installed name is near. `undefined-reference` and `undefined-citation` respell a key one typo off a label or entry. `duplicate-label` renames the later label (unsafe: its references then resolve to the first). The new `missing-bibliography` names the `.bib` files beside the document when citations have no bibliography. A command without its package loads the package most files use that defines it itself (`graphics` for `\includegraphics`, was `chickenize`).
- `feat` **Quick fixes for TeX errors.** `raised-error` repairs a runaway argument (closed at its line's or paragraph's end), a stray `}`, a missing `$`, an extra or misplaced `&`, a missing `\begin{document}`, a lonely `\item`, a `\\` with no line, a length without unit, a missing `\endcsname`, a group left open at `\right` or `\end` and a double superscript, which satex now raises like TeX. `undefined-control-sequence` respells a near name. A finding can offer several fixes.
- `feat` **Packages checked like libraries.** Analyzing a `.sty` or `.cls` calls each command it defines on unknown arguments in the document body and reports an error certain for every argument (`package-call-error`).
- `feat` **`misspelled-magic-comment`.** `% !rex program = tex` or `% !TeX progam` is reported early, with a fix to `!TeX` or `program`.
- `feat` **`low-contrast-color`.** Text below WCAG's 4.5:1 contrast (3:1 for large text) against its background is reported. The fix adjusts your `\definecolor` (`lints.low-contrast-color`).
- `feat` **`indistinct-colors`.** Colors side by side that look alike under protanopia, deuteranopia or tritanopia are reported. The fix suggests an Okabe-Ito color (`lints.indistinct-colors`).
- `feat` **Package rules.** `package-load-order` finds a later package that redefines an earlier one's command, the fix moves its `\usepackage` up. `redundant-package-load` deletes a load the class or an earlier package made already. `unknown-package-name` suggests an installed package a letter or two away (`graphix` gives `graphicx`).
- `feat` **PDF tagging lints and accessibility manager.** With `\DocumentMetadata{tagging=on}`: `tagging-incompatible-package`, `graphic-without-alt`, `pdfua-without-title`, `tagging-without-language`, `metadata-after-class`, `tagging-unsupported-engine`, `tagged-math-without-mathml`. `satex query tagging` lists the setup. "Accessibility…" edits tagging, PDF standard, language, title, alternative texts and table headers (`type_plugins.tagging`).
- `feat` **Early findings.** Text-only rules report on a sketch before the run: `comment-marker`, `user-pattern`, `clones`, two latexmkrc rules, `duplicate-package`, `unresolved-file`, `missing-graphic`. `satex lint` prints them at once as provisional, the run confirms or retracts each (`lints.early`).
- `feat` **Overfull preflight.** `overfull-line`, `overfull-box` and `wider-than-line` report pdflatex's `Overfull \hbox` by the same amount. A too wide `\includegraphics` gets the fix `width=\linewidth`.
- `feat` **Rule metadata.** `satex lint --explain`, `--rules`, `satex query --list`, the editor and the wiki show `since`. Summaries are short, rule numbers never change once released.
- `feat` **Package augmentations.** Per-package lint knowledge is switchable in `satex.yaml`. siunitx comes first: `inconsistent-precision` reads its rounding of `S` columns.
- `feat` **Spacing and punctuation fixes.** `primitive-tex-command` rewrites `\vskip` to `\vspace` and `\hskip` to `\hspace`. `command-terminated-space` covers `\TeX file` in TikZ nodes and `\fbox`. `scripts/spacing-sweep.py` checks every spacing fix on real documents. `math-punctuation` handles `$use?$ edge`.
- `fix` **A `\ref` inside an argument counts, and every cleveref form.** `\ref` in `\footnote`, `\emph`, `\textbf` or `\caption`, and `\cref`, `\Cref`, `\crefrange`, `\labelcref` and lists `a,b` with or without hyperref, mark their labels as used: no false `unused-label`, whose fix would delete them.
- `fix` **Prose rules skip math, code, keys and URLs.** 37 false positives in 20 rules fixed. A trigger, or the word it is judged by, in `$…$`, `\verb`, `\texttt`, `\url` or a listing is no prose: `?` before `$x$` starts no sentence. `scripts/lint-sweep.py` sets every prose rule's trigger in 23 contexts.
- `fix` **No findings from a run stopped before the body.** Such a run shows only why it stopped.

### Analysis

- `feat-fix` **No false certain errors from guesses inside unknown text.** A split that assumes where a delimiter lies inside unknown text marks its arms as approximated, so an error there is possible, not certain (a false `missing number` before `\include`). A run served from the kernel cache counts the same uses as the run that built it. A register write whose number a line-budget cut dropped is skipped, as the cut assumes, instead of making every count register unknown: the result no longer depends on the order satex tries the texts of an unknown.
- `perf` **Leaner checkpoints, honest stats.** A checkpoint shares the expansion sites instead of copying them: −6% peak memory on a 40-page document. `--stats` names the tokens replayed from caches apart from those run. A `--stats` run starts from the last build's own files too (the thesis example 3 runs → 1), and a run stopped by `limits.memory` is not stored.
- `feat` **Manuals for TikZ, pgf, primitives and more packages.** Hovers and Explain show pgf's manual, the pdfTeX manual, TeX by Topic and package docs in more formats (`docCommand`, `\DescribeMacro`, `desc` blocks, tcolorbox, enumitem, titlesec, xstring). Set by `docs.named_environments` and `docs.usage_blocks`.
- `feat-fix` **Option completion in listings and floats.** A body's `\csname lstlisting@\endcsname` is a call in the call graph, so `\begin{lstlisting}[` completes listings' keys. A float's `[…]` offers the placement letters not yet typed.
- `perf` **Faster cold runs of the examples.** The kernel cache loads into one name table (format phase 370 → 250 ms on every run). The tagging check reads the installation's roots from the cache instead of starting `kpsewhich` (slides example lint 650 → 125 ms). A document color finds its `\definecolor` call through an index instead of a scan of every expansion, quadratic under beamer themes. CPU per `satex lint`: hello 1.05 → 0.76 s (−28%), chapter −18%, slides 12.0 → 10.0 s (−17%), thesis −8%, same findings.
- `perf` **Box sizes for OpenType fonts.** XeTeX and LuaTeX text in a font loaded by file (`[lmroman10-regular]:…`) is measured from the font: advances, `GPOS` kerns, `liga` ligatures and glyph boxes, rounded as each engine rounds. Shaping satex does not follow keeps an interval, never a wrong size. TikZ under XeTeX no longer forks on unknown node sizes: the drawing example 300 s (time limit) → 3.8 s, 21.9k → 204 forks; the thesis example 300 s → 5.4 s, now with pdfTeX's findings; a two-node MWE 94 s (step limit) → 4.3 s, 7k → 0 forks. LuaTeX: luaotfload's fonts exist and have their `\fontdimen`s, and `\pdfextension` (pgf's literals) adds no size, so the drawing example 300 s → 7.2 s (25.5k → 214 forks), the MWE 3.4k → 8 forks.
- `perf` **Edits in a long thesis resume closer.** A thesis whose saved states for reruns were thinned to two late ones by the memory budget ran from the first line again for every typed word: the states where the document begins now always stay (outside `limits.checkpoint_memory`), so a body edit resumes at `\begin{document}` at the latest (a 1080M-step thesis, first edit in a chapter 396 → 314 s under load). After an edit, the first lines past the next two pages it ships keep a state, so the next edit there can meet the last run a page on, also once the edited chapter is read. Opening another file of the document no longer reruns it (100+ → 7 s).
- `perf` **Checkpoints within a memory budget.** Each saved state for reruns copied the graph, facts and sites anew, over half of a long thesis's memory. `limits.checkpoint_memory` (1 GiB) bounds them together: a 200k-line thesis peaks at 4.6 GiB instead of 6.1 GiB (−24%), same findings.
- `perf` **Far fewer path splits.** Four pgfmath divides 803 → 439 splits (−45%). l3fp over an aux position 112.6k splits and 37 s → 104 and 0.6 s (−99.9%, −98%). Tagged `\maketitle` and tables 281 s → 6 s (−98%). xcolor mix 88 → 4 splits (−95%).
- `perf` **Faster steps and long documents.** Figure-heavy documents save up to 25% of the time, other documents about 7%. 1000-page article 33.6 → 22.1 s (−34%), 1000-page scrbook −26%, tikz_200 peak 2.95 → 2.63 GB (−11%). A 20k-line paragraph 2.73 → 1.84 s (−33%), 1e5 `\loop` steps 0.66 → 0.53 s (−19%). Same steps and findings.
- `perf` **Kept call effects.** Calls of 200 steps or more replay when arguments and state match (`limits.call_memo_steps`, 0 turns it off, `limits.call_memo_verify: 1` checks each replay).
- `fix` **Control characters have LaTeX's category codes.** `^^@` is invalid, `^^L` and the other control characters are active, as latex.ltx sets them. They read as INITEX's before.
- `fix` **A runaway's paragraph fix stops before a heading.** A command the run saw end a paragraph (`\section`, through `\@startsection`'s `\par`) ends the argument's reach like `\par`.
- `fix` **No certain error from a split satex made.** A library error in a nested step of a path that took an arm over unknown text is possible, not certain (`\include` of a chapter whose `.aux` a cut left unknown).
- `fix` **Files a shell program may write.** A `\write18` program that names no output file may write any file: minted's `latexminted` config may exist, and no later error is certain. Its "executable is not installed" error was certain before.
- `fix` **A document started from its own dumped preamble.** `%&own` in `own.tex` reads the file once, which gives the state the format and mylatexformat's skip of its preamble give. The second `\documentclass` raised an error before.
- `fix` **Errors met while expanding or computing.** An undefined name inside `\edef`, `\message` or any expanding scan is reported like one the stomach meets. A call that does not match its parameter text is "Use of `\a` doesn't match its definition" and is dropped with the token (tex.web § 398), so expl3's expandable errors (`\fp_eval:n{(-8)^(1/3)}`) are findings. "Arithmetic overflow" (`\numexpr`, `\multiply`, `\divide` by zero), "Number too big", "Dimension too large" and "Improper `\spacefactor`" are raised as TeX's errors.
- `fix` **A prefix on one arm of an undecided conditional.** `\ifnum… \global\fi \count2=5` applied `\global` (or `\long`, `\protected`) on both arms after the join at `\fi`. Paths with different pending prefixes now stay apart until the assignment took them.
- `fix` **`\prevgraf` and `\deadcycles`.** `\prevgraf` is the vertical list's own: a `\vbox`, insertion or alignment starts at 0 and gives the outer count back (tex.web § 216). `\deadcycles` is 1 to `\maxdeadcycles` after an output run and 0 after a `\shipout`, no longer 0 for certain. A rule on the page waits on the contribution list like glue, so `\pagetotal` right after `\hrule` is the page before it.
- `fix` **`\lastbox` takes a plain box after `\unvbox`.** A list's box keeps whether it is an hbox or a vbox, also in a box register, so `\lastbox` takes it back as TeX does (tex.web § 1080). It was void, and a document's check for that raised a false error. An item that may be a box is never read as no box.
- `fix` **A possible error of the document is reported.** A TeX error the document's own text raises on one of several paths, such as a stray `}` inside an undecided `\ifnum`, is a warning "TeX may raise it". It was dropped. Library code stays assumed to compile.
- `fix` **An edit is read anew when a run resumes.** A rerun resumed from a checkpoint taken inside the edited line kept the part read before, so `\usetikzlibrary` typed letter by letter read as `\use` with the rest set as text. A begun line now counts whole when a checkpoint is checked.
- `fix` **Every TeX error of the document is reported.** `Missing number` after `\count1=`, `A <box> was supposed to be here`, `Missing { inserted`, `Extra \endgroup`, `Missing \right. inserted`, `Parameters must be numbered consecutively`, `Bad character code` and `Misplaced \noalign` were found but never shown, or hidden by a style note at the same place. `\begin{itemize}` ended by `\end{enumerate}` is an error, as in LaTeX. So is a class or package not found where the installation's files are all listed (the playground, fetching packages as named, keeps it a warning), and a `\usepackage` after `\begin{document}` is one error finding.
- `fix` **Numbered `align` runs to the end.** `\lastbox` after `\unvbox` takes back the box the list ended with, and what is left of an alignment row keeps its cells, so amsmath measures every column. A numbered `align` no longer marked the run incomplete with "Missing number" in amsmath.
- `fix` **A `#` with no parameter stays a `#`.** `\def\b{#1}` in a macro without parameters keeps the character, as TeX does. It leaked as an empty token, and KOMA's `\Ifiscount` expanded it forever: a thesis loading tocbasic went from 125 s, cut at the time limit, to 23 s reaching its end.
- `fix` **Build files give no entries or pictures.** The `.aux` read back no longer makes `\contentsline` arguments index entries, and `.ind`/`.bbl` environments no longer show as empty pictures.
- `fix` **A stray `#` in a definition is reported there.** `\def\ck#1{The year # is}` now gives TeX's "Illegal parameter number in definition" at the `#`, not only the later error at the use.
- `fix` **`limits.memory` counts what the process really holds.** The XeTeX thesis example peaked at 17.6 GB under an 8 GiB limit and was cut, it now reaches its end at 2.7 GB. Allocator overhead and resident memory count, and a loop under undecided conditionals no longer keeps every macro body it built.
- `fix` **No false errors from a joined property list.** A list linked on one path and flat on the other is read as one form per path: `\prop_gput:Nnn` into it raised "Paragraph ended before \__prop_pop_linked_prev:w" and "Argument has an extra }", 2 false errors → 0.
- `fix` **Loops over unknown text end.** A loop that walks unknown text without forking (l3prop's clear loop over a joined property list, lthooks at `\begin{document}` after beamer's templates) is cut after `limits.widen_after` rounds: its line 100M+ → 0.6M steps, beamer's internals cold 300 s (time limit) → 6 s.
- `fix` **Runs no longer stall or loop.** Joining and resuming waiting paths counts against `limits.walk_per_step`, so such a line is cut and reported instead of running for minutes. Fixed: `\DocumentMetadata` with graphicx at `\begin{document}`, `\@tryfcolumn` recursing 512 deep, `\clearnotecolumns`, captions looking endless at shipout, tcolorbox drawing code cut as a loop. A run waits at most `limits.lock_seconds` (60 s) for another build, then builds itself, and never waits on a lock it holds (chemfig's `\input chemfig.tex`).
- `fix` **pgfmath, stack and unknown-number precision.** Negative and positive parses stay apart, summaries no longer replace calls that rewrite a name they read and keep no text of other arguments (a false missing-number on a beamer title page), pgfmath stacks pop cleanly. TikZ bends to unknown width raise no false missing `\endcsname`, a signed random count now reaches the end, and TikZ pictures of unknown size end again.
- `fix` **Text colors after an early character.** Later text and page colors reach the Typeset view and color lints.
- `fix` **Sizes in math and on the page.** Big operators, delimiters, accents and scripts pick the right variant and size (the sample paper breaks its pages where pdflatex does). Displays add skips, so a here-float after one lands on its page.
