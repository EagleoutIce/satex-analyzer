Editor plugins

Every editor feature is a plugin. It reacts to what the run computed, such as a color, a length, a table or a figure, never to a command's name. Switch any of them off in satex.yaml or in the playground's settings.

Why interpret the code

TeX decides what a line means while it runs. Catcodes change, names get built, definitions come and go. A tool that only reads the text has to guess. SaTeX runs the kernel, the class and every package as TeX would, on every path at once, and joins the paths soundly where it cannot decide.

The other tools are good at what they do. SaTeX runs the code abstractly, so it can check what the others infer from names and text.
